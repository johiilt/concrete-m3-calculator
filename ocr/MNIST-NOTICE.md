# MNIST digit classifier

The browser loads 23,976 bytes of float32 weights extracted without retraining from the [ONNX Model Zoo MNIST-8 model](https://huggingface.co/onnxmodelzoo/mnist-8).

Source file SHA-256: 2f06e72de813a8635c9bc0397ac447a601bdbfa7df4bebc278723b958831c9bf. The little-endian tensors are stored in this order: Parameter5, Parameter6, Parameter87, Parameter88, Parameter193, Parameter194.

The upstream README specifies MIT. The ONNX Models repository and distribution metadata list Apache-2.0. See LICENSE-MNIST.txt for the repository license. No project photos or test images are included in the weights.
